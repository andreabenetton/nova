# Security policy

Nova is currently experimental. Do not deploy it to protect production traffic or economic value.

Security-relevant changes require:

- an explicit attacker model;
- affected invariants;
- downgrade and replay analysis;
- malformed-input behavior;
- resource-exhaustion analysis;
- test vectors and negative tests;
- independent review before an ADR can be accepted.

Do not report security claims as established unless supported by a reviewed specification, executable tests, and a clearly scoped threat model.
