# P-LAP security worklist

- exact Noise suite and transcript;
- replay windows;
- AEAD nonce uniqueness and crash recovery;
- discovery amplification limits;
- identity churn and Sybil resistance;
- queue and reassembly limits;
- stale locator handling;
- visible metadata analysis;
- downgrade behavior.
