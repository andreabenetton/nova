# P-LAP data-transfer stub

The first interoperable profile should provide encrypted, replay-protected, complete-SDU delivery with explicit packet numbers, key epochs, fragmentation fields, finite queues, and terminal Submission results.

The Path Provider contract can describe the actual properties of a Path. P-Stratum common is responsible for presenting the reliable atomic P-R baseline and may reject Paths that cannot support a selected P–R Interface delivery capability.
