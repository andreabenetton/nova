# P-LAP

The P-Stratum Link Adjacency Protocol discovers and establishes protected Paths with Nodes adjacent through a Nexus Fundamenta. It uses Adapters through `NOVA-IF-P-LAP-ADAPTER` and supplies Paths through `NOVA-IF-P-PATH-PROVIDER`.

The original P-Stratum paper is research input. This directory will become the normative P-LAP protocol specification.
