# P-RAP migration stub

Two migration levels are distinct:

1. locator or path migration inside one Binding technology, such as QUIC path migration;
2. replacement of one Binding instance or Binding type by another.

The first implementation may support only level 1. The Association model must still avoid identifying an Association by its current Binding instance.
