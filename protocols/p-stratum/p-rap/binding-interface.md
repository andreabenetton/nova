# P-RAP Binding boundary

The normative boundary is `contracts/interfaces/p-rap-binding/0.1.0/`. Bindings declare effective behavior, including message boundaries, reliability, ordering, congestion control, maximum unit size, and locator migration.

Binding names identify the integrated network and transport combination, for example IPv4-QUIC and IPv6-QUIC.
