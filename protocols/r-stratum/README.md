# R-Stratum

R-Stratum consumes only `NOVA-IF-P-R 0.2.0`. The Interface supplies the initial Close and Edge view, delivery capabilities, Obfuscated Degree, and complete SDU lifecycle.

R-Stratum must be implementable against any conforming P–R Interface provider without reading lower-stratum protocol or integration internals.

The original Nova paper remains research lineage for Routes, Trails, Flows, Grams, topology discovery, Link identification, Flow setup, data transmission, Beacon Facility, and Validating Facility. Incomplete paper mechanisms are not silently promoted into normative behavior.
