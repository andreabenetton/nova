# R-Stratum

R-Stratum consumes only `NOVA-IF-P-R`. It must be implementable using a mock P-Stratum and without reading P-LAP, P-RAP, Adapter, or Binding internals.

The original Nova paper provides research lineage for Routes, Trails, Flows, Grams, topology discovery, link identification, flow setup, data transmission, Beacon Facility, and Validating Facility. Those mechanisms are not yet complete normative specifications.
