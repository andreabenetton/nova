# O-Stratum glossary

This file owns O-Stratum terminology. It may be used together with the common glossary. P-Stratum and R-Stratum terminology is excluded except in an explicit Interface document.

**Segment**  
The O-Stratum SDU.

**Connection-oriented service**  
The O-Stratum service providing reliable, flow-controlled, full-duplex application communication.

**Connectionless service**  
The O-Stratum message-oriented service preserving application message boundaries without an application-visible connection.

**Application endpoint**  
An application-facing O-Stratum participant identified according to the O–Application Interface.
