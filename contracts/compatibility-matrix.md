# Compatibility matrix

Current contracts are experimental and require exact-version matching.

- Most Interfaces remain at `0.1.0`.
- `NOVA-IF-P-PATH-PROVIDER 0.1.0` is preserved as the original P-LAP/P-RAP-only contract.
- `NOVA-IF-P-PATH-PROVIDER 0.2.0` adds P-0AP as a Path Provider without modifying the published `0.1.0` directory.

Stable same-major negotiation is planned after `1.0.0`.
