# Task template: change an Interface contract

1. Name the Interface ID and current version.
2. State the externally observable behavior change.
3. Classify it as editorial, compatible, conditionally compatible, or breaking.
4. Update NIDL, behavior notes, invariants, and conformance scenarios.
5. Run compatibility analysis against the published baseline.
6. Regenerate derived artifacts.
7. Update every provider and consumer declaration.
8. Add an ADR when the architecture or compatibility policy changes.
