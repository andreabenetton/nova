## Normative specifications

The project intends stable normative Nova specifications to be implementable
royalty-free. The intended mechanism is the Open Web Foundation Final
Specification Agreement 1.0, Patent Only form (OWFa 1.0 Patent Only), applied
per named specification and version.

An OWFa commitment is **not** created automatically by:

- contributing to a `0.x` draft;
- merging a document;
- publishing a repository tag;
- applying CC-BY-4.0 to specification prose; or
- listing an interface in the roadmap.

A commitment applies only when all of the following are true:

1. the specification and exact version are listed in
   `patents/final-specifications.yaml`;
2. the list records the applicable signatory or Bound Entity;
3. the OWFa 1.0 Patent Only agreement has been validly executed for that
   specification; and
4. the executed record is retained by the project owner.

The repository initially lists no Final Specifications. Before any Nova 1.0
specification is designated final, the project must establish a contributor
patent-disclosure and authorization process. DCO sign-off is not a substitute
for a patent commitment.

The official OWFa 1.0 Patent Only form is maintained by the Open Web Foundation:
`https://www.openwebfoundation.org/the-agreements/the-owf-1-0-agreements-granted-claims/owfa-1-0-patent-only`.

Nothing in this document is a patent search, non-infringement opinion, or legal
advice.
