# Specification patent commitments

`final-specifications.yaml` is the machine-readable registry of Nova
specifications for which a valid OWFa 1.0 Patent Only commitment has been
executed. It is intentionally empty during the experimental `0.x` design phase.

A pull request adding an entry must include legal review, the exact immutable
specification version, the signatory or Bound Entity, and a reference to the
retained executed agreement. Do not place signatures or private addresses in
this public repository.
