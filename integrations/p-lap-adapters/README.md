# P-LAP Adapters

Adapters bind P-LAP to Nexus Fundamenta-specific behavior and implement `NOVA-IF-P-LAP-ADAPTER`.

Initial integrations:

- Simulated Adapter over the Virtual Fabric for deterministic P-LAP testing;
- Ethernet Adapter as the first real Nexus Fundamenta integration;
- internal virtual and Wi-Fi stubs for later design.
