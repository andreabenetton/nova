# P-RAP Bindings

Bindings bind P-RAP to integrated routed network and transport combinations and implement `NOVA-IF-P-RAP-BINDING`.

Initial integrations:

- Simulated Binding over the Virtual Fabric for deterministic P-RAP testing;
- IPv6-QUIC and IPv4-QUIC as the first real routed-underlay Bindings;
- TCP and raw UDP combinations as later compatibility or research Bindings.
