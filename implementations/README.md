# Implementations

Language- and platform-specific implementations. Normative behavior remains in canon, contracts, protocols, integrations, simulation, and compatibility profiles.

Initial Rust skeletons include P-0AP, the deterministic Virtual Fabric, a Simulated P-LAP Adapter, a Simulated P-RAP Binding, and their generated-interface placeholders. These are boundary demonstrations, not complete protocol implementations.
