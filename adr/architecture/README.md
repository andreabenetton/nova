# Architecture ADRs

Use the `ADR-ARCH-NNNN` sequence for decisions that constrain multiple strata or define system-wide architecture, dependency direction, normative authority, identity, privacy boundaries, or global invariants.

Do not place Interface-specific decisions here when they can be owned precisely by `interfaces/p-r/` or `interfaces/r-o/`.
