# P-0AP ADRs

Use the `ADR-P0AP-NNNN` sequence for decisions owned completely by the P-Stratum Zero-Underlay Association Protocol, including its deterministic behavior, control surface, and the simulation model it consumes.

A decision that also binds P-LAP or P-RAP belongs to `../` instead.
