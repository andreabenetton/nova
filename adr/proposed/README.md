# Legacy proposed ADR location

Proposed ADRs are now stored by architectural scope rather than by status.

Use the scope directories documented in [`../README.md`](../README.md). The ADR's `Status` field records whether it is proposed, accepted, rejected, or superseded.

This directory remains only as a compatibility marker and must not receive new ADRs.
