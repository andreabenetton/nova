# R-Stratum ADRs

Use the `ADR-R-NNNN` sequence for decisions private to R-Stratum design and behavior that can be implemented without changing another stratum's private model or an Interface contract.

Boundary-visible changes belong under `interfaces/p-r/` or `interfaces/r-o/`.
