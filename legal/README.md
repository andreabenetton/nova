# Licensing metadata

`license-policy.yaml` is the machine-readable source for path classification,
SPDX expectations, directory markers, and Rust crate license metadata.

Human-readable rationale and consequences are in `docs/licensing.md`.
Repository-wide legal notices are in `LICENSE-NOTICE.md`, `COPYRIGHT.md`,
`PATENTS.md`, `TRADEMARKS.md`, and `THIRD_PARTY_NOTICES.md`.

Validate changes with:

```sh
make licenses
```
