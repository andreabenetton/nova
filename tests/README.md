# Tests

Tests mirror architectural boundaries: contract, provider, consumer, peer-protocol, simulation, deterministic trace, integration, interoperability, adversarial, and performance.

P-0AP tests validate Path-level and inter-stratum behavior. P-LAP and P-RAP protocol conformance must additionally run through Simulated Adapter and Simulated Binding implementations so the actual peer protocols are exercised.
